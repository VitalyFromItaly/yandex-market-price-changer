для локального запуска телеграм бота 
установить зависимость LocalTunnel — это простой инструмент для создания публичного URL, который перенаправляет трафик на ваш локальный сервер.
npm install -g localtunnel

lt --port 3000
После запуска вы получите публичный URL, например https://abcd1234.loca.lt.
