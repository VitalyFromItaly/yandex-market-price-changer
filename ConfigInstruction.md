# Инструкция по настройке конфигурации торгового бота

Эта инструкция поможет вам настроить конфигурацию торгового бота для оптимальной работы. Разберем каждый раздел и параметр, объясним их значение и как правильно их настраивать.

## 1. Основная информация

```json
{
  "name": "default",
  "description": "Default trading configuration",
  "isActive": true
}
```

- **name**: Уникальное имя конфигурации. Используется для идентификации при наличии нескольких конфигураций.
- **description**: Описание конфигурации для удобства управления.
- **isActive**: Определяет, является ли эта конфигурация активной. `true` означает, что бот будет использовать эту конфигурацию при запуске.

## 2. Настройки биржи (exchange)

```json
{
  "exchange": {
    "testnet": true,
    "defaultLeverage": 10
  }
}
```

- **testnet**: Если `true`, бот будет работать в тестовой сети биржи без реальных денег. Для реальной торговли установите `false`.
- **defaultLeverage**: Стандартное плечо, применяемое для всех торговых позиций. Значение 10 означает 10x плечо (1:10).

## 3. Управление рисками (risk)

```json
{
  "risk": {
    "maxPositionSize": 10,
    "maxLeverage": 10,
    "maxRiskPerTrade": 0.01,
    "maxDailyLoss": 0.05,
    "stopLossPercent": 0.5,
    "takeProfitPercent": 1.0,
    "trailingStopActivation": 0.4,
    "trailingStopDistance": 0.2
  }
}
```

- **maxPositionSize**: Максимальный размер позиции в долларах США (в данном случае $10).
- **maxLeverage**: Максимальное разрешенное плечо. Даже если биржа предлагает больше, бот не будет использовать плечо выше этого значения.
- **maxRiskPerTrade**: Максимальный риск на одну сделку как доля от баланса. Значение 0.01 означает 1% от вашего баланса.
- **maxDailyLoss**: Максимально допустимые потери за день. При достижении этого порога бот остановит торговлю. Значение 0.05 означает 5% от вашего баланса.
- **stopLossPercent**: Процент изменения цены для автоматического стоп-лосса. Значение 0.5 означает, что стоп-лосс будет установлен на 0.5% от цены входа против вашей позиции.
- **takeProfitPercent**: Процент изменения цены для автоматического тейк-профита. Значение 1.0 означает, что тейк-профит будет установлен на 1.0% от цены входа в пользу вашей позиции.
- **trailingStopActivation**: Процент прибыли, при котором активируется трейлинг-стоп. 0.4 означает, что трейлинг-стоп активируется при достижении 0.4% прибыли.
- **trailingStopDistance**: Расстояние трейлинг-стопа от текущей цены. 0.2 означает, что стоп будет следовать за ценой на расстоянии 0.2%.

## 4. Стратегии торговли (strategies)

```json
{
  "activeStrategy": "scalping",
  "strategies": {
    "scalping": {
      "timeframe": "5m",
      "symbols": ["BROCCOLIUSDT", "ALCHUSDT", "STPTUSDT", "TRUMPUSDT"],
      "entryThreshold": 0.7,
      "exitThreshold": 0.4,
      "reversalThreshold": 0.8,
      "priceBufferSize": 300,
      "analysisWindowSize": 30,
      "minPriceChangePercent": 0.15,
      "initialStopLossPercent": 0.5,
      "takeProfitPercent": 1.0,
      "minHoldTimeMs": 30000,
      "maxHoldTimeMs": 300000,
      "useDualTimeframeAnalysis": true
    }
  }
}
```

- **activeStrategy**: Определяет, какая стратегия используется ботом. В данном случае это "scalping".

### Настройки стратегии скальпинга:

- **timeframe**: Временной интервал для анализа графика. "5m" означает 5-минутные свечи.
- **symbols**: Массив торговых пар, с которыми работает стратегия.
- **entryThreshold**: Пороговое значение для входа в позицию (от 0 до 1). Чем выше значение, тем строже условия для входа.
- **exitThreshold**: Пороговое значение для выхода из позиции (от 0 до 1). Чем ниже значение, тем быстрее бот будет закрывать позиции.
- **reversalThreshold**: Пороговое значение для разворота позиции (от 0 до 1). Высокое значение означает, что бот будет редко менять направление торговли.
- **priceBufferSize**: Размер буфера цен для анализа рынка.
- **analysisWindowSize**: Количество свечей, используемых для анализа.
- **minPriceChangePercent**: Минимальное изменение цены в процентах, необходимое для рассмотрения сигнала. 0.15 означает 0.15%.
- **initialStopLossPercent**: Начальный стоп-лосс в процентах от цены входа.
- **takeProfitPercent**: Тейк-профит в процентах от цены входа.
- **minHoldTimeMs**: Минимальное время удержания позиции в миллисекундах (30000 мс = 30 секунд).
- **maxHoldTimeMs**: Максимальное время удержания позиции в миллисекундах (300000 мс = 5 минут).
- **useDualTimeframeAnalysis**: Если `true`, бот будет использовать анализ двух временных интервалов для подтверждения сигналов.

## 5. Общие настройки (general)

```json
{
  "general": {
    "logLevel": "info",
    "enableMetrics": true,
    "dataBufferSize": 1000,
    "orderbookBufferSize": 300,
    "scalperMode": true,
    "defaultPositionSizeUsd": 10
  }
}
```

- **logLevel**: Уровень логирования. Варианты: "debug", "info", "warn", "error".
- **enableMetrics**: Если `true`, бот будет собирать метрики производительности.
- **dataBufferSize**: Размер буфера данных для хранения исторических цен и индикаторов.
- **orderbookBufferSize**: Размер буфера для хранения данных стакана ордеров.
- **scalperMode**: Если `true`, бот будет использовать режим скальпинга с более короткими сделками.
- **defaultPositionSizeUsd**: Стандартный размер позиции в долларах США.

## Рекомендации по настройке

### Для начинающих трейдеров:

1. **Тестовый режим**:
    - Оставьте `"testnet": true` пока вы полностью не освоитесь с ботом.

2. **Управление рисками**:
    - Начните с малых значений `maxPositionSize` и `maxRiskPerTrade` (например, 5$ и 0.005 соответственно).
    - Установите консервативный `maxDailyLoss` (например, 0.03 для 3%).
    - Используйте более широкие стоп-лоссы (`stopLossPercent`: 1.0) и скромные тейк-профиты (`takeProfitPercent`: 1.5).

3. **Стратегия скальпинга для начинающих**:
    - Используйте более длинные таймфреймы (`timeframe`: "15m").
    - Начните с популярных и стабильных пар (`symbols`: ["BTCUSDT", "ETHUSDT"]).
    - Установите более высокий `entryThreshold` (0.8) для снижения количества ложных сигналов.
    - Увеличьте `minHoldTimeMs` до 60000 (1 минута), чтобы избежать слишком быстрых выходов.

### Для опытных трейдеров:

1. **Боевой режим**:
    - Установите `"testnet": false` для торговли на реальном рынке.

2. **Управление рисками**:
    - Настройте `maxPositionSize` в соответствии с вашим капиталом (например, 1-2% от общего баланса).
    - Можно использовать более агрессивный `maxRiskPerTrade` (0.02 для 2%).
    - Для скальпинга используйте узкие стоп-лоссы (`stopLossPercent`: 0.3-0.5).
    - Настройте `trailingStopActivation` на 0.3 и `trailingStopDistance` на 0.15 для эффективного следования за трендом.

3. **Продвинутая настройка скальпинга**:
    - Используйте короткие таймфреймы (`timeframe`: "1m" или "3m").
    - Включайте высоколиквидные и волатильные пары.
    - Установите `minPriceChangePercent` в соответствии с волатильностью выбранных пар.
    - Для быстрого скальпинга уменьшите `minHoldTimeMs` до 15000 и `maxHoldTimeMs` до 180000.
    - Экспериментируйте с `useDualTimeframeAnalysis` для улучшения качества сигналов.

## Пошаговая инструкция по настройке

1. **Начните с базовой конфигурации**:
    - Скопируйте предоставленный шаблон конфигурации.
    - Измените `name` и `description` на ваши собственные.

2. **Настройка биржи**:
    - Решите, будете ли вы использовать тестовую сеть или реальную торговлю.
    - Установите подходящее плечо с учетом вашей готовности к риску.

3. **Настройка управления рисками**:
    - Определите максимальную сумму на одну сделку (`maxPositionSize`).
    - Установите лимиты риска (`maxRiskPerTrade` и `maxDailyLoss`).
    - Настройте параметры стоп-лосса и тейк-профита в соответствии с вашей стратегией.

4. **Настройка стратегии**:
    - Выберите подходящий таймфрейм.
    - Добавьте символы, которые вы хотите торговать.
    - Настройте пороговые значения входа/выхода в зависимости от желаемой частоты сделок.
    - Установите время удержания позиций в зависимости от вашего стиля торговли.

5. **Общие настройки**:
    - Выберите уровень логирования (рекомендуется начать с "info").
    - Настройте размеры буферов в зависимости от ресурсов вашей системы.
    - Установите размер позиции по умолчанию.

6. **Тестирование и корректировка**:
    - Запустите бота в тестовом режиме.
    - Мониторьте эффективность и вносите корректировки в параметры.
    - Когда вы удовлетворены результатами, переходите к реальной торговле.

## Применение конфигурации через API

Используйте следующий запрос для применения или обновления конфигурации:

```
POST /api/config
Headers:
  x-api-key: your-api-key
  Content-Type: application/json

Body: ваша конфигурация в формате JSON
```

Для активации существующей конфигурации:

```
PUT /api/config/{name}/activate
Headers:
  x-api-key: your-api-key
```

## Мониторинг и обслуживание

1. **Регулярно проверяйте результаты торговли** и корректируйте параметры.
2. **Обращайте внимание на изменения рыночных условий** - стратегия скальпинга может требовать корректировок при изменении волатильности.
3. **Делайте резервные копии успешных конфигураций** перед внесением значительных изменений.
4. **Используйте разные конфигурации для разных рыночных условий** (боковой рынок, тренд, высокая волатильность).

Следуя этой инструкции, вы сможете эффективно настроить торгового бота для вашего стиля торговли и уровня риска.
