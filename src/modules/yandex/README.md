# 🛒 Yandex Market Module

Модуль интеграции с Yandex Market API для управления товарами и ценами.

## 🏗️ Структура

```
yandex/
├── api/                    # Автогенерированные API клиенты
├── handlers/
│   └── price.changer.handler.ts    # Основной обработчик цен и товаров
├── services/
│   ├── campaign.service.ts         # Работа с кампаниями
│   └── offer.service.ts           # Управление товарами
└── yandex.domain.ts               # Типы и доменные модели
```

## 🚀 Основные возможности

### Управление ценами

- **Массовое обновление** цен с коэффициентами
- **Параллельные запросы** для ускорения обработки
- **Батчи по 50 товаров** (ограничение API)
- **Автоматическое округление** до копеек

### Управление остатками

- **Синхронное обновление** с ценами
- **Валидация количества** товаров
- **Поддержка складов** и остатков

### Создание товаров

- **Автоматические карточки** товаров
- **Извлечение брендов** из названий часов

- **Последовательное обновление остатков**

## 🔄 Workflow

### Обновление существующих товаров

1. **Подготовка данных** → Формирование запросов обновления
2. **Параллельные запросы** → Одновременное обновление цен и остатков
3. **Валидация результатов** → Проверка успешности операций
4. **Отчет об ошибках** → Сбор и анализ проблем

### Создание новых товаров

1. **Формирование карточек** → Создание карточек товаров
2. **Создание в API** → Отправка запроса на создание
3. **Обновление остатков** → Установка количества для созданных товаров

## 📊 API Интеграция

### Поддерживаемые эндпоинты

- `POST businesses/{businessId}/offer-prices/updates` - обновление цен
- `PUT campaigns/{campaignId}/offers/stocks` - обновление остатков
- `POST businesses/{businessId}/offer-mappings/update` - создание карточек

### Обработка ошибок

- **Детальное логирование** всех API запросов
- **Сбор ошибок** по батчам и товарам
- **Повторные попытки** при временных сбоях
- **Fallback механизмы** для критических операций

## 🖼️ Интеграция с изображениями

### Автоматический поиск

- **Извлечение брендов** из названий товаров

- **Включение URL** прямо в запрос создания карточки
- **Мгновенное отображение** созданных товаров

### Поддерживаемые бренды

- Rolex, Omega, Apple, Casio, Seiko и 30+ других
- Автоматическое определение по названию
- Умная обработка моделей и артикулов

## ⚡ Производительность

### Оптимизации

- **Promise.all** для параллельных операций
- **Батчевая обработка** (50-100 товаров за раз)
- **Минимальные задержки** между запросами
- **Эффективная память** без утечек

### Ограничения API

- **50 товаров** максимум в batch для обновления цен
- **100 товаров** максимум для создания карточек
- **Rate limiting** с автоматическими задержками

## 🛡️ Надежность

### Обработка ошибок

- Индивидуальная обработка ошибок для каждого товара
- Сохранение результатов даже при частичных сбоях
- Детальные отчеты с описанием проблем

### Валидация данных

- Проверка обязательных полей
- Валидация форматов цен и количества
- Санитизация входящих данных

## 🔧 Конфигурация

### Переменные окружения

- `YANDEX_MARKET_BASE_URL` - базовый URL API
- API токены настраиваются пользователями через бота

### Настройки пользователей

- **API Token** - токен доступа
- **Campaign ID** - ID кампании
- **Business ID** - ID бизнеса
- **Price Coefficient** - коэффициент цен (по умолчанию 1.8)
