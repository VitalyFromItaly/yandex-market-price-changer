# 📄 Parser Module

Модуль для парсинга Excel/CSV файлов с данными о товарах и ценах.

## 🏗️ Структура

```
parser/
├── constants/
│   └── sku-patterns.ts           # Паттерны для извлечения SKU
├── domain.parser.ts              # Типы и модели парсера
├── encoding-fixer.ts             # Исправление кодировок
├── index.ts                      # Главный экспорт
├── parser.ts                     # Основной парсер Excel/CSV
├── simple-parser.ts              # Упрощенный парсер
└── run-simple-parser.ts          # Тестовый скрипт
```

## 🚀 Основные возможности

### Поддерживаемые форматы
- **Excel файлы** (.xlsx, .xls)
- **CSV файлы** с различными разделителями
- **Автоопределение** формата файла
- **Исправление кодировок** (UTF-8, Windows-1251)

### Извлечение данных
- **Артикулы (SKU)** из различных форматов
- **Названия товаров** с очисткой
- **Цены** с валидацией
- **Количество** товаров
- **Автоматическое сопоставление** колонок

## 📊 Обработка данных

### Распознавание колонок
Автоматическое определение колонок по названиям:
- **Артикул:** "артикул", "sku", "код", "номер"
- **Название:** "название", "наименование", "товар", "продукт"
- **Цена:** "цена", "стоимость", "price"
- **Количество:** "количество", "остаток", "stock", "qty"

### Извлечение SKU
Поддерживаемые форматы артикулов:
- Цифровые: `123456789`
- Буквенно-цифровые: `ABC123DEF`
- С дефисами: `ABC-123-DEF`
- С точками: `ABC.123.DEF`
- Смешанные форматы

### Очистка данных
- **Удаление HTML тегов** из названий
- **Нормализация пробелов** и переносов строк
- **Конвертация цен** в числовой формат
- **Валидация количества** товаров

## 🔧 Использование

### Основной парсер
```typescript
import { Parser } from './parser';

const parser = new Parser();
const result = await parser.parseFile('/path/to/file.xlsx');

console.log(`Обработано: ${result.parsedProducts.length} товаров`);
console.log(`Ошибки: ${result.errors.length}`);
```

### Простой парсер
```typescript
import { SimpleParser } from './simple-parser';

const parser = new SimpleParser();
const data = await parser.parseExcelFile('/path/to/file.xlsx');
```

## 📋 Структура результата

### ParsedProduct
```typescript
interface ParsedProduct {
  sku: string;              // Артикул товара
  name: string;             // Название товара
  price: number;            // Цена товара
  quantity?: number;        // Количество (опционально)
  originalData: any;        // Исходные данные строки
}
```

### ParsingResult
```typescript
interface ParsingResult {
  parsedProducts: ParsedProduct[];   // Успешно обработанные товары
  errors: ParseError[];              // Ошибки парсинга
  totalRows: number;                 // Общее количество строк
  successfulRows: number;            // Успешно обработанных строк
}
```

## 🛡️ Обработка ошибок

### Типы ошибок
- **Файловые ошибки** - проблемы с чтением файла
- **Структурные ошибки** - неверная структура данных
- **Валидационные ошибки** - некорректные значения
- **Кодировочные ошибки** - проблемы с кодировкой

### Детализация ошибок
```typescript
interface ParseError {
  row: number;              // Номер строки с ошибкой
  field: string;            // Поле с ошибкой
  value: any;               // Некорректное значение
  message: string;          // Описание ошибки
  originalData: any;        // Исходные данные строки
}
```

## ⚡ Производительность

### Оптимизации
- **Потоковое чтение** больших файлов
- **Пакетная обработка** строк
- **Кэширование** регулярных выражений
- **Ленивая инициализация** парсеров

### Ограничения
- **Максимальный размер файла:** 10MB
- **Максимальное количество строк:** 10,000
- **Таймаут обработки:** 30 секунд

## 🔍 Валидация

### Обязательные поля
- **SKU** - не должен быть пустым
- **Название** - минимум 3 символа
- **Цена** - положительное число

### Опциональные поля
- **Количество** - по умолчанию 1
- **Описание** - дополнительная информация

## 🌐 Поддержка кодировок

### Автоопределение
- **UTF-8** (приоритет)
- **Windows-1251** (фолбэк)
- **UTF-16** для некоторых Excel файлов

### Исправление проблем
- Автоматическое исправление кракозябр
- Конвертация между кодировками
- Валидация корректности символов
