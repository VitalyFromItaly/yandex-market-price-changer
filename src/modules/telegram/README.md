# 📱 Telegram Module

Модуль обработки Telegram бота для управления ценами на Yandex Market.

## 🏗️ Структура

```
telegram/
├── bots/
│   ├── price-changer-bot/     # Основной бот управления ценами
│   │   ├── handlers/          # Обработчики команд и событий
│   │   │   ├── file-upload.handler.ts      # Загрузка и обработка файлов
│   │   │   ├── menu-commands.handler.ts    # Команды меню
│   │   │   ├── api-settings.handler.ts     # Настройки API
│   │   │   └── ...
│   │   ├── price-changer.bot.ts           # Главный класс бота
│   │   └── price-changer.keyboard.ts      # Клавиатуры
│   └── shared/               # Общие компоненты для ботов
├── api/                      # REST API эндпоинты
└── ui/                       # UI компоненты (клавиатуры)
```

## 🤖 Основной функционал

### Загрузка файлов

- **Поддерживаемые форматы:** Excel (.xlsx, .xls), CSV
- **Максимальный размер:** 10MB
- **Автоматическое удаление** после обработки
- **Валидация** формата и содержимого

### Команды бота

- `/start` - запуск и приветствие
- `/profile` - настройка API Yandex Market
- `/files` - просмотр загруженных файлов
- `/cleanup` - очистка временных файлов

### Обработка файлов

1. **Загрузка** → Сохранение в `static/temp/`
2. **Парсинг** → Извлечение данных товаров
3. **Сравнение** → Анализ с Yandex Market API

4. **Обновление** → Изменение цен/создание карточек
5. **Очистка** → Удаление временных файлов

## 🔧 Настройка API

Пользователи настраивают через бота:

- **API Token** - токен доступа к Yandex Market
- **Campaign ID** - идентификатор кампании
- **Business ID** - идентификатор бизнеса
- **Price Coefficient** - коэффициент изменения цен

## 🗑️ Автоочистка файлов

Файлы удаляются автоматически:

- ✅ После успешной обработки
- ❌ При ошибках API
- 🚫 При ошибках парсинга
- 👤 При проблемах с пользователем
- 🕐 Старые файлы (24 часа)

## 📊 Отчеты

Бот предоставляет детальные отчеты:

- Количество обновленных товаров
- Количество созданных карточек
- Список ошибок с описанием
- Процент успешности операций

## 🛡️ Безопасность

- Валидация всех входящих данных
- Ограничения размера файлов
- Проверка прав доступа пользователей
- Безопасное хранение API ключей

## 🚀 Расширение

Для добавления новых команд:

1. Создайте handler в `handlers/`
2. Зарегистрируйте в `price-changer.bot.ts`
3. Добавьте в меню клавиатуру
4. Обновите документацию
